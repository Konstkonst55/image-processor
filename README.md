# Image Processor

Консольная программа на `C++17` для пакетной обработки изображений в последовательном и параллельном режимах.

## Зависимости

В каталоге `third_party` должны находиться `stb_image.h` и `stb_image_write.h`.

Для генерации изображений требуется `Pillow`. Устанавливать его нужно в виртуальное окружение - на современных `Ubuntu`/`Debian` прямая установка через `pip` в системный `Python` заблокирована (`PEP 668`).

```bash
python3 -m venv venv
source venv/bin/activate
pip install Pillow
```

> [!NOTE]
> Если `venv` или `pip` ещё не установлены, сначала поставьте недостающие пакеты:
> 
> ```bash
> sudo apt update
> sudo apt install python3-pip python3-venv
> ```
> 
> Вариант без виртуального окружения (не рекомендуется - может повредить системный `Python`):
> 
> ```bash
> pip3 install Pillow --break-system-packages
> ```

## Генерация тестовых изображений

Скрипт создаёт указанное количество изображений случайных размеров и форматов `PNG`, `JPG`, `JPEG`, `BMP` и `TGA`. По умолчанию файлы помещаются в каталог `images`.

```bash
python scripts/generate_images.py 50
```

Можно указать другой каталог:

```bash
python scripts/generate_images.py 50 --output-dir test-images
```

## Сборка

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

## Запуск

```bash
./build/image_processor
```

Программа запросит входную и выходную директории, операцию и режим обработки. В параллельном режиме дополнительно потребуется указать количество рабочих потоков.

Результаты сохраняются в PNG с именем исходного файла и суффиксом `.processed.png`.
